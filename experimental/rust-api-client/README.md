# Rust API client (experimental)

An older attempt: a Windows app (Rust + egui, built on `hinge-rs`) that likes via Hinge's unofficial API.
Since Hinge app 10 the like is sent blind (profiles can't be read over REST), and it has never been verified against a real account.
Tested only against a mock server (`tests/e2e/run_e2e.py`). Use `../../iphone` instead.
