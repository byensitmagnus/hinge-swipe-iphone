# Security

This tool runs locally and talks only to your own iPhone over USB. It stores one small file (`iphone/state.json`, a like counter) and no credentials.

Found something that could expose a user's data, or a way the tool could be made to act on someone else's phone? Please report it privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for it.

Out of scope: Hinge's terms of service. Automating Hinge breaks them; that risk is stated in the README and is the user's to accept.
